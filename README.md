# Linear Algebra for Machine Learning

This repository contains Python notebooks that explore fundamental linear algebra concepts commonly used in machine learning and data science.

The goal of this repository is to build an intuitive understanding of mathematical foundations through practical examples, visualizations, and hands-on implementation in Python.

## Topics Covered

### 1. Vectors and Transformations
- Vector representation
- Vector addition and subtraction
- Scalar multiplication
- Dot product
- Vector magnitude (norm)
- Linear transformations
- Shear transformations
- Visualization of transformations

### 2. Singular Value Decomposition (SVD)
- Understanding matrix decomposition
- Components of SVD
- SVD implementation using NumPy
- SVD implementation using Scikit-Learn
- Matrix reconstruction
- Dimensionality reduction concepts

## Technologies Used

- Python
- NumPy
- Matplotlib
- Scikit-Learn
- Jupyter Notebook
